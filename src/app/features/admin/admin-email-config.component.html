Enterprise Security

  • Database-Driven Settings

    Settings are stored in dbo.SystemSettings. No configuration files or code changes needed for credentials.

  • AES-256 Encryption

    Passwords are stored with enc:v1: AES-256 encryption. Plaintext is never exposed in the UI, logs, or disk.

  • Zero Secrets in Code

    Both appsettings.json and repository sources contain zero plaintext email passwords.

  • Failover Architecture

    Includes direct MailKit SMTP delivery with automatic fallback proxy bridging for enterprise environments.
